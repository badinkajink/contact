How to use this template

  • Each slide is a <section class="slide"> on a 1280×720 canvas. The engine scales it to fit the window.
  • Keys: → / space next, ← back, R reading view, F fullscreen, ? help.
  • Links: deck.html#7 opens slide 7. ?mode=read gives the scrolling web-page view.
  • PDF: uv run export.py template.html, or print from Chrome (the page size is already 1280×720).
  • No build step, no framework. It still opens in ten years.
Reader notes live in <aside class="notes">. They are hidden while presenting and appear under each slide in the reading view.

Math

Inline math such as $\abs{f_t} \le \mu f_n$ is set with KaTeX. Display math:

$$\K_\mu = \{\, \vf = (f_n, \vf_t) \;:\; f_n \ge 0,\ \norm{\vf_t} \le \mu f_n \,\}$$

Shared macros: \vf \vw \vp \nhat \that \K \norm{} \abs{} \R. Add your own with window.DECK_MACROS before deck.js runs.

Worked example. With $\mu = 0.5$, the cone's half-angle is $\alpha = \arctan 0.5 \approx 26.6^\circ$.

    $\arctan 1 = 45^\circ$.
  2. What happens to the cone when $\mu = 0$?
    answer
    It collapses to a single ray along the normal.

def in_cone(f_n, f_t, mu):
    """Coulomb: the floor can push, never pull, and drag at most mu times as hard."""
    return f_n >= 0 and abs(f_t) <= mu * f_n
