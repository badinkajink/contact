Axes in box style and origin style

Left: Plot.fig maps the limits $[-2.2, 2.2] \times [0, 10]$ onto the area inside the margins with separate x and y scales, and F.axes draws the bottom and left spines with outward ticks, round tick values from 1-2-5 steps, a light grid and both axis labels. The rotated y label sits left of the widest tick label. Right: a plain Fig keeps one scale for both axes, so the unit circle stays round; F.axes with origin: true draws math-style axes through $(0, 0)$ with arrowheads, ticks that cross the lines and no label at the crossing. The dashed line is $y = x/2$, clipped to the axes range.

Function graphs clipped to the plot box

  • F.curve samples $f$ at 401 points and clips each segment to the box.
  • A segment whose ends lie beyond opposite edges is dropped, so $\tan x$ and $1/x$ show no vertical line at their poles.
  • Tick labels can be pairs such as [Math.PI, "$π$"].
F.curve(Math.tan, {color: C.blue});
F.curve(Math.sin, {color: C.red,
  dash: true});
F.curve((x) => 1 / x, {color: C.green});
F.legend([{name: "tan $x$", ...}]);
The figure shows $\tan x$, $\sin x$ and $1/x$ on $[-2\pi, 2\pi]$ with the y range cut to $[-3, 3]$. Every curve is one SVG path with one subpath per visible piece: the clipper (Liang-Barsky on each segment) starts a new subpath wherever the curve re-enters the box. The asymptote rule drops a segment only when one end is above the box and the other below, which a continuous curve sampled at 401 points never does inside the range shown. Non-finite values ($1/0$) also break the line. The legend is F.legend with line samples; dash: true gives the 6 px / 5 px dash of fig.js.

Parametric curves, polylines, and scatter points

Left: the unit circle (dashed) and its image under $A = \begin{bmatrix} 1.6 & 0.6 \\ 0.3 & 0.9 \end{bmatrix}$, both drawn by F.param with equal axis scales. The orange triangle extends past the plot box on three sides; F.polyline with a fill clips the polygon with Sutherland-Hodgman and the outline with the same segment clipper as F.curve. Right: 25 points $y = 0.8x + 0.5 + 0.6\,\varepsilon$ with $\varepsilon$ from a seeded Gaussian generator, the least-squares line computed in the page (the legend shows its coefficients), and each residual as a two-point polyline. Scatter markers are open circles here; shape "square", "x" and "+" also exist.

Contour lines of a quadratic bowl with a gradient-descent path

$J(\vz) = \tfrac12 (z_1^2 + 8 z_2^2)$, step $\alpha = 0.22$, from $\vz_0 = (-2.8, 1.0)$.

const lines = F.contour(J,
  [0.25, 0.5, 1, 2, 4, 8, 16],
  {color: C.gray, labels: true});
F.polyline(path, {color: C.red});
F.scatter(path, {r: 3.5, fill: C.red});
Marching squares runs on a grid of one cell per 5 px (here 107 by 59 cells), with each crossing point found by linear interpolation along its cell edge. Crossings are keyed by the edge they lie on, so the segments of neighbouring cells join exactly into polylines, and the readout reports how many polylines came back and whether each ellipse closed. Labels sit on the longest line of each level with a white halo, at the first of several arc-length positions that keeps them inside the box and clear of earlier labels. The red path is gradient descent, $\vz_{k+1} = \vz_k - \alpha \nabla J(\vz_k)$: the $z_2$ component is multiplied by $1 - 8\alpha = -0.76$ each step, so it zig-zags, while $z_1$ shrinks by $0.78$.

Heat maps with the sequential and diverging colormaps

Left: Himmelblau's function $f(x, y) = (x^2 + y - 11)^2 + (x + y^2 - 7)^2$ on a log scale, with its four minima as the four darkest-free white basins. F.heat evaluates the function at cell centres (one cell per 3 px), writes the colors into an offscreen canvas and embeds it as a PNG data URL in an SVG image, which works from file://. Right: the saddle $x^2 - y^2$ on the diverging map with symmetric limits, so zero is white; the dashed zero contour is the pair of diagonals. Colorbars take their map and range from the image (of: im) or from explicit options.

Feasible region of four linear inequalities and a disk

$x_1, x_2 \ge 0$, $x_1 + 2x_2 \le 4$, $3x_1 + x_2 \le 6$, $x_1^2 + x_2^2 \le r^2$. Dashed: levels of $2x_1 + 3x_2$.

const R = F.region((x, y) => x >= 0 &&
  y >= 0 && x + 2 * y <= 4 &&
  3 * x + y <= 6 && x * x + y * y <= r * r);
R.lines;  // boundary polylines
F.region evaluates the predicate on a grid of one cell per 4 px, finds each boundary crossing by 16 bisection steps along its cell edge, and fills every inside piece as a counter-clockwise polygon in one SVG path, so shared cell edges cancel under the nonzero rule and no seams show. The boundary is stroked from the same crossings. A corner of the set is cut within one cell, about 4 px. The readout takes the largest value of $2x_1 + 3x_2$ over the boundary points; the true maximum of a linear function over this set lies on its boundary, so the grid estimate is low by less than the cell size times $\sqrt{13}$. Moving the slider redraws the whole figure.

Negative gradient field of a quadratic

$J(\vz) = \tfrac12 \vz^\top Q \vz$ with $Q = \begin{bmatrix} 1 & 0.6 \\ 0.6 & 2 \end{bmatrix}$; arrows show $-\nabla J = -Q\vz$.

const q = F.quiver((x, y) =>
  [-(x + 0.6 * y), -(0.6 * x + 2 * y)],
  {n: 13, color: C.ink});
q.scale;  // world units per unit of field
F.quiver samples the field at the centres of a 13 by 13 grid and scales every arrow by one factor, chosen so the longest arrow spans 0.85 of a cell; the readout prints that factor. Arrows are centred on their sample points (pivot "mid"). The contours of $J$ are drawn first in gray, and every arrow crosses them at a right angle only when the axes have equal scales, which is why this figure uses equal: true. Arrow heads shrink with short arrows so that the arrows near the minimum stay readable.

Image of the integer grid under a 2×2 matrix




F.grid2([[a, b], [c, d]],
  {original: true, square: true});
F.grid2 draws the images of the lines $x = i$ and $y = i$ under $\vv \mapsto A\vv$ in light blue, the images of the two axes in dark blue, and the arrows $A\ve_1 = (a, c)$ and $A\ve_2 = (b, d)$. The pale yellow parallelogram is the image of the unit square; its signed area is $\det A = ad - bc$, printed in the readout. The gray grid underneath is the original. The number of lines is chosen from $A^{-1}$ so the image covers the plot box; for a singular $A$ every line collapses onto the column space and the figure shows one line.

Surfaces in 3D with painter's ordering

Left: the bowl $\tfrac12(x^2 + 2y^2)$ colored by height on the heat map. Right: the saddle $x^2 - y^2$ in the default pale yellow, with height scaled by 0.6 for display. Each grid cell is one quadrilateral; F.surface3 sorts them by the depth of their centres along the viewing direction and paints the far ones first. Shading darkens faces turned away from a light near the viewer. On the right the axes are drawn before the surface, so the surface hides the parts of the axes behind it.

Histogram of 2000 Gaussian samples with the density overlaid

const h = F.hist(xs, {bins: 32,
  range: [-4, 4], density: true});
F.curve(pdf, {color: C.red});
F.vline(1, {label: "+1"});

Samples come from a seeded generator (mulberry32 and Box-Muller), so the figure is the same on every load.

With density: true the bar heights are count divided by (number of samples in range times bin width), so the bars have total area 1 and sit on the same scale as the standard normal density $\varphi(x) = e^{-x^2/2} / \sqrt{2\pi}$. The readout gives the sample mean, the sample standard deviation and the fraction of samples within one standard deviation of zero, which should be near $0.683$. The dashed lines at $\pm 1$ are F.vline with labels.

Probability mass of the sum of two dice

F.axes({xticks: false, ylabel:
  "probability", ystep: 0.05});
F.bars(p, ["2", "3", ..., "12"], {
  values: true, fill: (v, i) =>
    i === 5 ? C.cone : "#cccccc",
  fmt: (v) => Math.round(36 * v) + "/36"});

$P(\text{sum} = s) = (6 - \lvert s - 7 \rvert)/36$; the most likely sum is 7, with probability $6/36 = 0.167$.

F.bars centres bar $i$ at $x = i$ with width 0.7 and writes the category labels where the x tick labels would go, so the axes are drawn with xticks: false. The value labels sit 4 px above each bar; fmt turns the probabilities into sixths of six. Fill can be one color, an array, or a function of the value and index, used here to mark the mode.

Colormaps heat, diverging, and gray

The sequential map runs white, pale yellow (#ffff99, the friction-cone color), orange, dark red. Its CIE lightness falls monotonically from 100 to 19, so a grayscale print keeps the order of the values, and low values stay distinguishable from the white page through their yellow tint. The diverging map runs from dark blue through white at $t = 0.5$ to dark red, with lightness symmetric within 3 units about the middle. The right figure is computed in the page from each map, so it is a live check of the stops in plot.js.

Strip chart beside a running pendulum simulation

const S = Plot.strip("#f-strip", {w: 640,
  h: 300, window: 8, series: [
  {name: "$θ$ (rad)"}, {name: "$ω$ (rad/s)"}]});
S.push(t, [theta, omega]);  // once a frame
A damped pendulum, $\ddot\theta = -(g/L)\sin\theta - c\dot\theta$ with $g = 9.81$ m/s$^2$, $L = 1$ m and $c = 0.3$ 1/s, released from $\theta = 2$ rad and integrated by semi-implicit Euler at $h = 1/120$ s, two steps per animation frame. The first 5 s are simulated when the page loads so the chart is filled in print and reading views. The simulation runs only while this slide is shown. Plot.strip keeps the last 8 s, redraws once per animation frame, and grows its y range to round values around everything pushed since the last restart.
